# 中長期テーマの提案（Claude Code で実行・API料金なし）

関心のある分野（任意）: $ARGUMENTS

1. `python -m kabu.cli rules` を実行し、ルールに従う（短期の値動き予想・目標株価・売買推奨は書かない）。
2. WebSearch（合計5回程度まで）で、国内外のマクロ経済・産業・政策の直近のニュースや統計を調べ、今後数ヶ月〜数年で
   日本の上場企業の業績に構造的な影響を与えそうなテーマを3〜4個選ぶ。
3. 各テーマについて、次をまとめる:
   - 何が・なぜ・どの期間で変わるか（裏付けとなる数値・政策・設備投資計画を出典つきで）
   - 恩恵を受けるバリューチェーンと、関連しそうな東証上場企業（証券コードつき・各テーマ3社程度）
   - 逆風・不確実性
   - 市場での注目度（すでに広く知られ株価が大きく動いたテーマなら、織り込みが進んでいる可能性として明記）
4. `reports/themes_<今日の日付>.md` に書き、チャットでは短く一覧を示す。
5. 最後に「詳しく調べるなら `/kabu-theme <テーマ名>` を実行してください」と案内する。
