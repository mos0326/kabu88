# kabu88 — 中長期テーマ分析と「数値による監査」の自分専用ツール

日本株を対象に、AI（Claude）が **中長期の投資テーマを調べ、関連企業を洗い出し、外部データの数値で楽観論に反証を当てる** ツールです。
AIは「株価を当てる予言者」ではなく、**人間の意思決定を補佐するデータ整理・監査エンジン** として設計しています。

> ⚠️ このツールの出力は投資助言ではありません。最終的な判断はご自身で行ってください。

---

## 💴 お金をかけない使い方（おすすめ）

**追加の料金ゼロで、すべての機能が使えます。**

| 部分 | 使うもの | 料金 |
| --- | --- | --- |
| 株価・指数・ドル円・PER/PBR | Yahoo Finance | 無料（キー不要） |
| 信用残（信用倍率・買い残）・空売り残高 | JPX（日本取引所）の公表データ | 無料（キー不要） |
| 会社予想EPS・BPS・進捗率・修正履歴（任意） | J-Quants **Free プラン** | 無料（登録のみ・12週間遅れ） |
| AIによるテーマ調査・監査 | **Claude Code**（`/kabu-theme` など） | 0円（お使いのサブスクリプションの範囲内） |

Claude API キーは不要です。API（従量課金）は「ダッシュボードのボタンから直接AIを動かしたい」場合だけの任意機能で、
使う場合も月の予算上限（既定 $3）で止まるようにしています（→ [API を使う場合の節約設定](#api-を使う場合の節約設定)）。

### Claude Code での使い方
このリポジトリを Claude Code（デスクトップアプリ / CLI / Web）で開き、次のように入力します。

| 入力 | できること |
| --- | --- |
| `/kabu-themes` | 直近のニュースから中長期テーマの候補を提案 |
| `/kabu-theme AIデータセンター拡大による液冷需要` | テーマを調べ、関連企業（最大5社）を数値で監査して保存 |
| `/kabu-audit 6857 5803` | 指定した銘柄を、数値と開示資料・ニュースで監査して保存 |

結果は `reports/` に Markdown レポートとして保存され、ダッシュボードの「🗂 履歴と検証」タブでも見られます。
数値の取得（`python -m kabu.cli prepare`）と、保存前の検証・短期予測ガード（`python -m kabu.cli finalize`）はコードが行うので、
API で実行した場合と同じルール・同じ形式になります。

## 設計の考え方

### LLMの弱点
| 弱点 | 内容 |
| --- | --- |
| リアルタイム需給と数値計算の欠落 | 板情報・HFT・日々の資金フロー・信用残の増減など、短期の値動きを決める数値をリアルタイムに扱えない |
| 「織り込み済み」のタイムラグ | ニュースや開示から論理的に「上がる」と推論できた時点で、市場はすでに織り込んでいることが多い（高値掴みの原因） |

### 改善策と実装
| 改善策 | このツールでの実装 |
| --- | --- |
| **A. 短期予測の排除と中長期テーマへの特化** | ① AIへの指示（`python -m kabu.cli rules`）で短期予測・目標株価・売買指示をハードリミットとして禁止（理由も説明）<br>② 出力の形式に価格予測の欄を持たせない（「調査の優先度」まで）<br>③ `kabu/guard.py` が出力を検査し、短期予測・目標株価・売買タイミングに当たる文を削除して記録<br>④ Web検索・Web取得・PDF（決算短信・有報・説明資料）で一次情報を読み込む（RAG）。時間軸は数ヶ月〜数年 |
| **B. 定性データと定量データの分離** | ① 株価・PER/PBR・会社予想・信用残・空売りは **外部データから取得**（`kabu/quant.py`、AIは一切計算しない）<br>② 過熱・割高・需給・織り込みの **フラグはしきい値でコード判定**<br>③ AIには数値を「与えられたデータ」として渡し、記憶の数値を使わせない<br>④ AIは「ニュースは良いが信用買い残が膨らみ上値が重い」のような **定性と数値の食い違い** を指摘する |

### 処理の流れ
```
テーマ（自分で入力 / AIに提案させる）
   │
   ├─[定性] Claude（Claude Code または API）+ Web検索・Web取得・添付PDF
   │         決算短信・有報・統計・ニュースを出典つきで調査 → 関連企業を選ぶ
   │
   ├─[定量] Yahoo Finance … 株価・指数・ドル円（1年騰落・200日線乖離・RSIなど）  ←無料
   │        JPX公表データ … 銘柄別信用残（日次PDF）・空売り残高（日次Excel）       ←無料
   │        J-Quants      … 会社予想EPS/BPS・進捗率・修正履歴（Freeは無料）、有料プランなら最新値
   │         └→ 監査フラグをコードで判定（過熱 / 織り込み / 割高 / 需給 / 業績 / イベント）
   │
   └─[監査] Claude が 定性 × 定量 × フラグ を突き合わせる
             → 中長期の変化・数値の監査・織り込み度・強気/弱気材料・追うべきKPI・次の確認ポイント
             → 調査の優先度（深掘り / 監視 / 優先度低）※売買推奨ではない
             → 形式チェック・短期予測ガード → 保存（あとで事後検証）
```

## データの接続先

| 接続先 | 料金 | 何に使うか | 設定 |
| --- | --- | --- | --- |
| **Yahoo Finance** | 無料 | 株価・日経平均・TOPIX(1306)・ドル円、PER/PBRの代替 | なし |
| **JPX 公表データ** | 無料 | [銘柄別信用取引残高](https://www.jpx.co.jp/markets/statistics-equities/margin/01.html)（日次PDF）→ 信用倍率・買い残の出来高比・上場株数比／[空売り残高](https://www.jpx.co.jp/markets/public/short-selling/index.html)（日次Excel）→ 大口の空売り | なし（`KABU_USE_JPX=0` で無効） |
| **J-Quants API V2**（JPX公式） | Free は無料 | 会社予想EPS・BPS（→ 会社予想ベースのPER/PBRを現在株価で計算）、進捗率、上方/下方修正の履歴、過去の開示日から次の決算日を推定 | `JQUANTS_API_KEY`, `JQUANTS_PLAN` |
| **Claude Code** | サブスクの範囲内 | テーマ調査・監査（`/kabu-theme` など） | なし |
| **Claude API** | 従量課金（任意） | ダッシュボード・CLIから直接AIを動かす | `ANTHROPIC_API_KEY` |

- JPX の公表ページに載るのは直近数日分だけなので、取得したファイルは `data/cache/jpx/` に保存して履歴をためます（1日1回程度・個人利用の範囲で）。
  信用残PDFは数字が崩れて抽出されることがあるため、「売残 = 一般 + 制度」「買残 = 一般 + 制度」の検算が合った行だけを使います。
- J-Quants の有料プラン（Light 以上で最新のバリュエーション・決算日、Standard 以上で J-Quants 版の信用残・空売り）は、
  使う場合だけ `JQUANTS_PLAN` を変えてください（[プラン別の提供データ](https://jpx-jquants.com/ja/spec/data-spec)）。
  無料の JPX データで需給は見られるので、必須ではありません。

## セットアップ

Python 3.11 以上が必要です。

```bash
git clone https://github.com/mos0326/kabu88.git
```

```bash
cd kabu88
```

```bash
python -m venv .venv && source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

`.env` は空のままでも動きます（J-Quants の Free プランを使う場合は `JQUANTS_API_KEY` だけ設定）。ダッシュボードの起動:

```bash
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。キーなし・ネットなしで画面だけ確認したい場合は、サイドバーの「デモモード」をオンにしてください。

### ダッシュボード

| タブ | できること | 料金 |
| --- | --- | --- |
| 🧭 テーマ分析 | テーマ → 関連企業 → 数値 → 監査（ボタン実行は API） | API（Claude Code なら0円） |
| 🔍 個別銘柄の監査 | 気になる銘柄を数値と開示資料・ニュースで監査（ボタン実行は API） | API（Claude Code なら0円） |
| 📊 数値チェック（AIなし） | 銘柄リスト全体の過熱・割高・需給フラグを一覧（信用倍率つき） | 無料 |
| 🗂 履歴と検証 | 過去の分析（Claude Code 実行分も）を表示。**あなたの判断とメモ**を保存。分析時点からの騰落率を「AIの優先度」ごとに日経平均と比べて事後検証 | 無料 |
| ⚙️ 銘柄リスト | 数値チェックの対象銘柄（`config/universe.csv`）を編集 | 無料 |

### コマンドライン

```bash
python -m kabu.cli quant
```

```bash
python -m kabu.cli prepare 6594 7011 --theme "AIデータセンター拡大による液冷需要"
```

```bash
python -m kabu.cli budget
```

`prepare` / `finalize` / `rules` / `schema` は Claude Code のスキルが使うコマンドです。API で実行するコマンド（`themes` / `theme` / `audit`）もあります（`python -m kabu.cli -h`）。

## API を使う場合の節約設定

Claude API（従量課金）を使う場合も、料金がかさまないようにしています。

| 仕組み | 内容 |
| --- | --- |
| 月の予算上限 | `KABU_MONTHLY_BUDGET_USD`（既定 $3）に達するとボタンからのAI実行を止める。サイドバーに今月の使用額を表示 |
| 控えめな既定値 | 企業数5、Web検索3回（1回 約1.5円）、Web取得2回、取得ページは1万5千トークンまで |
| 思考量（effort）を抑える | 調査は `low`、監査は `medium` |
| AI呼び出しの節約 | 関連企業の抽出は、リサーチメモの決まった形式から正規表現で読む（読めたときはAIを呼ばない） |
| キャッシュ | 検索の続きを再送するときは自動キャッシュで前半を1/10の料金で読む。数値データもディスクにキャッシュ |
| 同じテーマの再実行に注意 | 7日以内に同じテーマを分析していたら、履歴で無料で見られることを表示 |
| モデルの選択 | サイドバーで Opus 5.5（既定・高品質）/ Sonnet 5.5（約半額）/ Haiku 5.5（最安）を選べる |
| 実行前の見積もり | 設定から1回あたりの料金の上限目安を表示し、実行後は実際の料金を記録 |

Anthropic の Console でも、APIキーの月の利用上限（Limits）を設定しておくと確実です。

## 監査フラグ（コードで判定）

しきい値は `kabu/config.py` の `THRESHOLDS` で変更できます。

| 区分 | 例 |
| --- | --- |
| 過熱 | RSI14 ≥ 75、25日線乖離 ≥ +15% |
| 織り込み | 200日線乖離 ≥ +40%、3ヶ月 ≥ +40%、1年 ≥ +100% |
| 割高 | 予想PER ≥ 40倍、PBR ≥ 8倍 |
| 需給 | 信用倍率 ≥ 5倍、買い残 ≥ 平均出来高の10日分、買い残が4週で +30%、大口空売り残高 ≥ 3%、業種空売り比率 ≥ 50% |
| 業績 | 会社予想が営業 −10% 以下、下方修正（上方修正は「情報」） |
| イベント | 決算発表まで14日以内（J-Quants Free では過去の開示日からの推定） |
| データ | バリュエーションの基準日が30日以上前 |

## ファイル構成

```
app.py                 ダッシュボード（Streamlit）
.claude/skills/        Claude Code 用の手順（/kabu-theme, /kabu-audit, /kabu-themes）
kabu/
  ai.py                Claude API: テーマ提案・調査・企業抽出・監査。ルール（rules）と出力形式（schema）もここ
  guard.py             短期予測ガード（短期予測・目標株価・売買指示の文を削除して記録）
  quant.py             定量レイヤー: 外部データの数値と監査フラグ（AIは使わない）
  jpx.py               JPX 公表データ（信用残PDF・空売り残高Excel）の取得と解析
  jquants.py           J-Quants API V2 クライアント（ディスクキャッシュつき）
  data.py              Yahoo Finance とデモ用の合成データ
  indicators.py        株価から計算する指標
  pipeline.py          API実行の流れと、Claude Code 用の prepare / finalize
  costs.py             API料金の計算・見積もり・月の予算
  report.py            Markdown レポート
  schema_check.py      監査JSONの形式チェック
  store.py             分析結果・判断メモの保存、事後検証
config/universe.csv    数値チェックの対象銘柄
data/runs/, reports/   分析結果とレポート（個人のデータのため git には含めない）
tests/                 テスト（Claude と J-Quants は偽のクライアントで代用・無料）
```

このリポジトリは公開設定のため、分析結果・レポート・判断メモ・キャッシュは `.gitignore` で除外しています。
