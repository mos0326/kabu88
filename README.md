# kabu88 — 中長期テーマ分析と「数値による監査」の自分専用ツール

日本株を対象に、AI（Claude）が **中長期の投資テーマを調べ、関連企業を洗い出し、外部APIの数値で楽観論に反証を当てる** ツールです。
AIは「株価を当てる予言者」ではなく、**人間の意思決定を補佐するデータ整理・監査エンジン** として設計しています。

> ⚠️ このツールの出力は投資助言ではありません。最終的な判断はご自身で行ってください。

---

## 設計の考え方

### LLMの弱点
| 弱点 | 内容 |
| --- | --- |
| リアルタイム需給と数値計算の欠落 | 板情報・HFT・日々の資金フロー・信用残の増減など、短期の値動きを決める数値をリアルタイムに扱えない |
| 「織り込み済み」のタイムラグ | ニュースや開示から論理的に「上がる」と推論できた時点で、市場はすでに織り込んでいることが多い（高値掴みの原因） |

### 改善策と実装
| 改善策 | このツールでの実装 |
| --- | --- |
| **A. 短期予測の排除と中長期テーマへの特化** | ① システムプロンプトで短期予測・目標株価・売買指示をハードリミットとして禁止（理由も説明）<br>② 出力スキーマに価格予測の欄を持たせない（「調査の優先度」まで）<br>③ `kabu/guard.py` が出力を検査し、短期予測・目標株価・売買タイミングに当たる文を削除して記録<br>④ Web検索・Web取得・PDF（決算短信・有報・説明資料）で一次情報を読み込む（RAG）。時間軸は数ヶ月〜数年 |
| **B. 定性データと定量データの分離** | ① 株価・PER/PBR・ROE・会社予想・信用残・空売りは **外部APIから取得**（`kabu/quant.py`、AIは一切計算しない）<br>② 過熱・割高・需給・織り込みの **フラグはしきい値でコード判定**<br>③ AIには数値を「与えられたデータ」として注入し、記憶の数値を使わせない<br>④ AIは「ニュースは良いが信用買い残が膨らみ上値が重い」のような **定性と数値の食い違い** を指摘する |

### 処理の流れ
```
テーマ（自分で入力 / AIに提案させる）
   │
   ├─[定性] Claude + Web検索・Web取得・添付PDF … 決算短信・有報・統計・ニュースを出典つきで調査
   │         └→ 関連企業を抽出（バリューチェーンの段階ごと）
   │
   ├─[定量] Yahoo Finance … 株価・指数・ドル円（1年騰落・200日線乖離・RSIなど）
   │        J-Quants（JPX公式）… バリュエーション・会社予想・進捗率・修正履歴・信用残・空売り・決算日
   │         └→ 監査フラグをコードで判定（過熱 / 織り込み / 割高 / 需給 / 業績 / イベント）
   │
   └─[監査] Claude が 定性 × 定量 × フラグ を突き合わせる
             → 中長期の変化・数値の監査・織り込み度・強気/弱気材料・追うべきKPI・次の確認ポイント
             → 調査の優先度（深掘り / 監視 / 優先度低）※売買推奨ではない
             → 短期予測ガードで最終チェック → 保存（あとで事後検証）
```

## 必要な接続（コネクト）

アプリが使う接続は `.env` に設定します（claude.ai のコネクタとは別物です）。

| 接続先 | 必要度 | 何に使うか | 設定 |
| --- | --- | --- | --- |
| **Claude API**（Anthropic） | 必須 | テーマ調査・関連企業の抽出・監査。Web検索/Web取得もここから | `ANTHROPIC_API_KEY`（[console.anthropic.com](https://console.anthropic.com/) で発行） |
| **Yahoo Finance** | 自動（キー不要） | 株価・日経平均・TOPIX(1306)・ドル円。J-Quantsがないときの PER/PBR | なし |
| **J-Quants API V2**（JPX公式） | 強く推奨 | 下表のとおり | `JQUANTS_API_KEY`, `JQUANTS_RPM`（[jpx-jquants.com](https://jpx-jquants.com/) でAPIキー発行） |

J-Quants はプランによって使えるデータが変わります（[公式のプラン別一覧](https://jpx-jquants.com/ja/spec/data-spec)）。

| データ | 使えるプラン | このツールでの用途 |
| --- | --- | --- |
| バリュエーション指標（PER・予想PER・PBR・ROE・時価総額） | 全プラン（Freeは12週間遅れ） | 割高感の判定 |
| 財務情報（決算短信の数値） | 全プラン（Freeは12週間遅れ） | 会社予想の増収・増益率、進捗率、上方/下方修正の履歴、予想配当利回り |
| 決算発表予定日 | 全プラン | 「決算が近い」フラグ、次の確認ポイント |
| 信用取引残高 | Standard以上 | 信用倍率・買い残の出来高比（上値の重さ）・買い残の4週変化 |
| 業種別空売り比率 / 空売り残高報告 | Standard以上 | 業種・市場全体の空売り比率、大口の空売り残高 |
| TDnet 適時開示（決算短信PDF） | TDnetアドオン | 最新の決算短信PDFを自動取得してAIに読ませる |

- Free プランは12週間遅れのデータで、1分5リクエストまでです。実用には Light（決算・バリュエーションが最新）以上、需給まで見るなら Standard 以上がおすすめです。
- 契約プラン外のデータは自動でスキップされ、「不足していたデータ」として画面に表示されます。AIにも「データなし」として伝わります。
- サイドバーの「J-Quants 接続テスト」か `python -m kabu.cli check` で、どのデータが使えるか確認できます。

## セットアップ

Python 3.11 以上が必要です。

```bash
git clone https://github.com/mos0326/kabu88.git
```

```bash
cd kabu88
```

```bash
python -m venv .venv && source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

`.env` を開いて `ANTHROPIC_API_KEY`（と、あれば `JQUANTS_API_KEY`）を設定してから起動します。

```bash
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。キーを入れずに画面だけ確認したい場合は、サイドバーの「デモモード」をオンにしてください（株価は架空の合成データになります）。

## 使い方（ダッシュボード）

| タブ | できること |
| --- | --- |
| 🧭 テーマ分析 | テーマを入力（または「AIにテーマを提案させる」）→ 関連企業の抽出 → 数値取得 → 監査。決算短信・有報などのPDFを添付して読ませることもできます |
| 🔍 個別銘柄の監査 | 気になる銘柄（最大10）を、数値と開示資料・ニュースで監査 |
| 📊 数値チェック（AIなし） | 銘柄リスト全体の過熱・割高・需給フラグを一覧（無料・APIキー不要） |
| 🗂 履歴と検証 | 過去の分析を再表示。銘柄ごとに **あなたの判断とメモ** を保存。分析時点からの騰落率を「AIの優先度」ごとに日経平均と比べて、AIの優先度づけが役立っているかを事後検証 |
| ⚙️ 銘柄リスト | 数値チェックの対象銘柄（`config/universe.csv`）を編集 |

## 監査フラグ（コードで判定）

しきい値は `kabu/config.py` の `THRESHOLDS` で変更できます。

| 区分 | 例 |
| --- | --- |
| 過熱 | RSI14 ≥ 75、25日線乖離 ≥ +15% |
| 織り込み | 200日線乖離 ≥ +40%、3ヶ月 ≥ +40%、1年 ≥ +100% |
| 割高 | 予想PER ≥ 40倍、PBR ≥ 8倍 |
| 需給 | 信用倍率 ≥ 5倍、買い残 ≥ 平均出来高の10日分、買い残が4週で +30%、大口空売り残高 ≥ 3%、業種空売り比率 ≥ 50% |
| 業績 | 会社予想が営業 −10% 以下、下方修正（上方修正は「情報」） |
| イベント | 決算発表まで14日以内 |
| データ | バリュエーションの基準日が30日以上前（Freeプランの遅延など） |

## 料金の目安

- Claude API: 既定モデルは Claude Opus 5.5（入力 $4 / 出力 $20 per 100万トークン）。Web検索の量や添付PDFの量で変わりますが、テーマ分析1回でおおむね $0.5〜2 程度が目安です。実際の使用トークン数は結果画面の下に表示されます。Web検索・Web取得は回数に応じて別料金です（サイドバーで上限を設定できます）。
- 「📊 数値チェック」は AI を使わないので無料です。
- 安く試したいときは、Web検索の回数・調べる企業数を減らすか、`.env` の `KABU_MODEL` で別のモデルを指定してください。

## ファイル構成

```
app.py              ダッシュボード（Streamlit）
kabu/
  ai.py             Claude: テーマ提案・調査（Web検索/Web取得/PDF）・企業抽出・監査。ハードリミット付きのプロンプトとスキーマ
  guard.py          短期予測ガード（短期予測・目標株価・売買指示の文を削除して記録）
  quant.py          定量レイヤー: 外部APIの数値と監査フラグ（AIは使わない）
  jquants.py        J-Quants API V2 クライアント
  data.py           Yahoo Finance（株価・PER/PBRの代替）とデモ用の合成データ
  indicators.py     株価から計算する指標（騰落率・移動平均乖離・RSI・ボラティリティ）
  pipeline.py       テーマ分析・個別監査の全体の流れ
  store.py          分析結果・判断メモの保存、事後検証
  charts.py         チャート
config/universe.csv 数値チェックの対象銘柄
data/runs/          分析結果（個人データのため git では無視する設定）
tests/              テスト（AIとJ-Quantsは偽のクライアントで代用）
```
